# Built, Not Born

The website for Built, Not Born, my speaking program for schools and youth groups. It introduces the message, shows what students and staff walk away with, and lets organizers send a booking request.

## Features

- Landing page with the program's story, takeaways and the audiences it serves
- Booking request form handled by Netlify Forms, with a hidden spam trap
- Thank-you page after a request is sent
- Responsive layout for phone and desktop

## Built with

HTML · CSS · Netlify Forms

## Getting started

No build step or install needed.

    git clone https://github.com/robertandersonux/built-not-born-site.git
    cd built-not-born-site

Then open `index.html` in your browser. The booking form only sends requests on the deployed Netlify site, not on your local copy.
